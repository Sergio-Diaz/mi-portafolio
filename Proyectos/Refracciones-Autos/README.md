# Sistema de Gestión - Refacciones Automotrices

Plataforma orientada a la venta, control y catalogación de refacciones y accesorios automotrices. Encuentra las mejores piezas para tu vehículo con calidad, precio y garantía en un solo lugar.

---

## Características Principales

- **Catálogo de Refacciones:** Búsqueda rápida y organizada de piezas, autopartes y accesorios por marca, modelo y año del vehículo.
- **Garantía y Calidad:** Módulo para la gestión de especificaciones técnicas, compatibilidad y certificados de garantía por producto.
- **Control de Inventario:** Monitoreo en tiempo real de existencias en almacén y alertas de stock.
- **Gestión de Ventas y Precios:** Módulo para la consulta de precios competitivos y emisión de comprobantes de compra.

---

## Beneficios

- Ubicación precisa de autopartes compatibles.
- Transparencia en precios, cotizaciones y garantías.
- Optimización en el proceso de consulta y surtido de piezas.

---

## Tecnologías Utilizadas

- **Backend:** C# / .NET
- **Base de Datos:** SQL Server
- **Frontend:** HTML5, CSS3, JavaScript
