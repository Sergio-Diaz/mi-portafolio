# Project Management System

Sistema de gestión de proyectos de desarrollo de software diseñado para optimizar la administración operativa y financiera de tus proyectos.

---

## Misión

Proveer una herramienta eficiente para la gestión de proyectos de desarrollo de software, permitiendo a los desarrolladores y equipos controlar entregables, pagos y el avance financiero de manera integral.

---

## Visión

Ser la plataforma líder en gestión de proyectos de desarrollo, reconocida por su simplicidad, eficiencia y capacidad de adaptación a las necesidades de los equipos de software.

---

## Características Principales

- **Control de Entregables:** Seguimiento y gestión del avance de los hitos del proyecto.
- **Gestión Financiera:** Monitoreo de pagos, presupuesto e ingresos del proyecto.
- **Seguimiento Integral:** Vista clara del estado de salud técnico y financiero del desarrollo.

---

## Tecnologías Utilizadas

- **Backend:** C# / .NET
- **Base de Datos:** SQL Server
- **Frontend:** HTML5, CSS3, JavaScript
