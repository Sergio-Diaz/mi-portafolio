# GestorPOS - Sistema de Punto de Venta

## Descripción

Sistema de punto de venta optimizado para comercios locales. Permite registrar ventas en tiempo real, gestionar catálogo de productos, controlar caja diaria e imprimir tickets de compra.

## Características Principales

- Registro rápido de ventas y cobranza.
- Control de inventario en tiempo real.
- Generación de tickets de venta y reportes de caja.

## Tecnologías Utilizadas

- **Lenguaje / Framework:** C# / .NET
- **Base de Datos:** SQL Server / SQLite
- **Despliegue:** Instalador ejecutable para Windows
