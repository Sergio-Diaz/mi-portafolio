# ERP Cooperativa

## Descripción

Sistema de gestión administrativa y contable diseñado para la automatización de procesos operativos, control financiero y manejo de socios dentro de una organización cooperativa.

## Características Principales

- Módulo de gestión de socios y aportaciones.
- Control de solicitudes financieras y créditos.
- Conciliación bancaria y reportes contables.

## Tecnologías Utilizadas

- **Lenguaje:** C# (.NET)
- **Arquitectura:** Monolítica / Capas de servicio
- **Base de Datos:** SQL Server
