# Sistema de Gestión de Clientes (CRM)

## Descripción

Plataforma integral diseñada para administrar clientes, contactos e interacciones de manera eficiente. Permite centralizar la información comercial, optimizar el seguimiento de prospección y mejorar las relaciones con los clientes desde una interfaz centralizada.

---

## Funcionalidades Principales

- **Gestión de Clientes:** Registro, actualización y categorización detallada del perfil de cada cliente.
- **Directorio de Contactos:** Administración organizada de personas clave, roles e información de contacto asociada a cada cuenta.
- **Historial de Interacciones:** Registro exhaustivo de llamadas, correos electrónicos, reuniones y notas de seguimiento.
- **Pipeline y Seguimiento Comercial:** Monitoreo del estado de las oportunidades de negocio y etapas del ciclo de venta.
- **Búsqueda y Filtros Avanzados:** Ubicación rápida de expedientes y segmentación según el estado o tipo de cliente.

---

## Beneficios

- **Eficiencia Operativa:** Reduce el tiempo dedicado a la búsqueda de información dispersa.
- **Mejor Atención al Cliente:** Acceso inmediato al historial completo de interacción antes de cada contacto.
- **Centralización de Datos:** Mantiene la base de conocimiento comercial en una sola plataforma segura.

---

## Tecnologías Utilizadas

- **Backend:** C# / .NET
- **Base de Datos:** SQL Server
- **Frontend:** HTML5, CSS3, JavaScript
