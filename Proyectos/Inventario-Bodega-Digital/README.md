# SaaS - Gestión de Inventario y Stock

## Descripción
Plataforma web tipo SaaS orientada al control integral de inventarios, almacenamiento y movimientos de stock para pequeñas y medianas empresas.

## Características Principales
* Control de entradas, salidas y transferencias de mercancía.
* Gestión de alertas de stock mínimo.
* Reportes analíticos de rotación de producto.

## Tecnologías Utilizadas
* **Backend:** C# / .NET Core (Web API)
* **Frontend:** HTML5, CSS3, JavaScript
* **Base de Datos:** SQL Server
