# Sistema de Control e Inventario de Mudanzas (Packing List)

## Descripción
Este módulo está diseñado para la gestión y registro detallado de cada caja, bulto o mueble transportado en un servicio de logística o mudanza. Asigna un número de identificación único a cada elemento, detallando su contenido y registrando el estado físico en el que se recibe para el traslado.

---

## ¿Para qué sirve?

* **Control de inventario:** Permite verificar detalladamente al inicio y al final del servicio que todos los objetos cargados en el vehículo lleguen completos a su destino.
* **Localización rápida:** Facilita la ubicación exacta de objetos específicos dentro de las cajas sin necesidad de abrir todo el equipaje.
* **Reclamaciones y seguros:** Funciona como un comprobante y prueba formal ante eventuales daños, pérdidas o faltantes durante el traslado.

---

## Información que incluye

| Campo | Descripción |
| :--- | :--- |
| **Número de bulto** | Código o correlativo único asignado a cada caja, paquete o mueble. |
| **Descripción del contenido** | Detalle de los artículos almacenados (ej. *"Libros de sala"*, *"Vajilla de cocina"*). |
| **Habitación de destino** | Indicación del área o espacio asignado en la nueva ubicación (ej. *Recámara principal*, *Cocina*, *Sala*). |
| **Observaciones** | Registro del estado inicial del paquete u objeto (ej. *rayones previos*, *golpes*, *nivel de fragilidad*). |
